# TrustCard_Bonus_Calculator
A simple, single-page calculator that shows what the Trust Freedom Card new-to-Trust sign-up bonus is worth at different spend levels.
What it does
Lets you set your qualifying spend (up to S$15,000) and shows the bonus Max Miles you would earn.
Converts the miles into an estimated cash value and an effective cashback rate.
Compares that cashback rate with a benchmark card (default 1.5%) that you can change.
Shows a chart of the effective return at each spend level, so you can see where each tier unlocks.
Shows how far you are from the next tier.
Includes referral codes for HeyMax and the Trust Freedom Card.
